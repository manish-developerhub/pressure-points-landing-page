Theme: Student PressureTagline: We all carry grades, but we hide the pressure.Concept Note (For Judge):
Pressure Points is not just a poster, it's a mirror. Every college student looks fine from outside, but inside there are 5 invisible points where the pressure hits the most. This project visualizes those 5 points that we never talk about.My design shows a student carrying a backpack, but the backpack is not books — it's the weight we all feel daily.The 5 Pressure Points:1. CGPA — The Number That Defines YouOne number decides your worth in class, internships, family functions. The fear of dropping 0.1 keeps you awake at 3 AM.2. PLACEMENTS — The Future FearFinal year hasn't come, but the question is here: "Package kitna hai?" LinkedIn comparisons, coding tests, rejected emails.3. EXPECTATIONS — The Invisible BagParents, relatives, professors, society. Everyone expects you to be the topper, the earner, the perfect child. You can't disappoint them.4. DEADLINES — The Never-Ending LoopAssignments, exams, projects, finals — one ends, another starts. To-do list never becomes done.5. ANXIETY — The Silent OneThe one we don't show. Self-doubt, comparison, loneliness even in a crowded classroom.Design Language:Style: Pixel + Glitch + Neon — because pressure feels like a system overload.
